# Demo recording run — 2026-10-25

The terminal run behind [`docs/demo.gif`](../docs/demo.gif) (a DRY RUN: nothing was deleted). Same MacBook as
[`dry-run-2026-10-25.md`](dry-run-2026-10-25.md), about 50 minutes later, recorded with asciinema 3.2.1 in a
104×50 terminal starting at 2026-10-25T21:35:26+0700. Commands: `df -h ~`, then `sweep --redact --top 5`.
The two commands were typed by a small driver script (50 ms per key) and then run exactly as typed; the output is
the tool's own. `--redact` swaps the names under your home for labels: projects become
`~/<dir>/<project-NNN>/<artifact>`, other files and folders e.g. `~/Downloads/<item-NN>` (the top-level folder stays),
named temp entries `$TMPDIR/<scratch-NN>`, and a model reason that repeats the hidden name gets `<name>` instead.
`~/Library`, dot-folders, Docker, macOS/Node temp names and artifact names such as `node_modules` stay readable.
Sizes, verdicts and totals are unchanged.
